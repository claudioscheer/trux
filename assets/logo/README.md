# Trux logo

The mark is a lowercase **t** whose crossbar is an **x**, with a curved foot.

| File | Use |
| --- | --- |
| `trux-logo.svg`, `trux-logo-{1024,512,256,64,32}.png` | the mark in Trux blue on a transparent background (the approved source files) |
| `trux-logo-light.svg`, `trux-logo-light-{1024,512,256,64,32}.png` | the mark in light blue, for dark backgrounds |
| `trux-wordmark.svg`, `trux-wordmark-light.svg` | the mark with the "Trux" wordmark (Inter SemiBold, as outlines), for light and dark backgrounds |
| `trux-icon.svg`, `trux-icon-512.png` | app icon: the white mark on a rounded Trux blue square (favicons, touch icons, the VS Code extension) |
| `trux-og.png` | 1200x630 social card |

## Colors

| Color | Hex | Use |
| --- | --- | --- |
| Trux blue | `#1E3A8A` | the mark and the primary color on light backgrounds |
| Light blue | `#93C5FD` | the mark and the primary color on dark backgrounds |
| Ink | `#1F2937` | the wordmark on light backgrounds (white on dark) |

## Regenerating

Everything except the source files is generated by `generate.py`, which also writes the copies used by the docs site
(`website/assets/images/logos/`, `website/assets/opengraph/card-base-2.png`, `website/static/` favicons,
`site.webmanifest`, and `og-image.png`) and the VS Code extension (`tooling/vscode-trux/images/`):

```bash
pip install cairosvg pillow fonttools
python3 assets/logo/generate.py --inter /path/to/Inter-VariableFont_opsz,wght.ttf
```

The wordmark is drawn from the [Inter](https://rsms.me/inter/) variable font, converted to outlines so the SVGs don't
depend on installed fonts.
