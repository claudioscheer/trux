# Trux documentation site

The source of <https://thea1lab.github.io/trux/>, built with [Hugo](https://gohugo.io) (extended, 0.140 or newer)
and the [Lotus Docs](https://github.com/colinwilson/lotusdocs) theme, which Hugo fetches as a Go module (so Go is needed
too).

```bash
cd website
hugo server          # http://localhost:1313/trux/
hugo --gc --minify   # build into website/public/
```

| Path | Contents |
| --- | --- |
| `hugo.toml` | site configuration, theme module, and mounts of `../docs`, `../examples`, and `outputs/` |
| `content/docs/` | the documentation pages; sidebar order comes from each page's `weight` |
| `content/docs/design-notes/_content.gotmpl` | publishes the design notes in `../docs/*.md` without moving them |
| `data/landing.yaml` | the landing page |
| `layouts/` | the `include` shortcode and small overrides of Lotus Docs templates (each file says what changed) |
| `static/docs/js/components/prism-trux.min.js` | Trux syntax highlighting for Prism |
| `assets/scss/_trux-brand.scss`, `assets/docs/scss/custom/colors/_trux.scss`, `assets/scss/style.scss` | the brand colors (see below) |
| `assets/images/logos/`, `assets/opengraph/`, `static/favicon*`, `static/og-image.png` | logo, social cards, and favicons, generated by [`../assets/logo/generate.py`](../assets/logo/) |
| `layouts/partials/page-markdown.md` | the Markdown version of each page (see below) |
| `check-markdown-output.sh` | CI check of the Markdown output: no leftover shortcodes, no broken `llms.txt` links |
| `outputs/` | real program output shown on the site, written by `update-example-outputs.sh` (CI runs it with `--check`) |

## Brand colors

The primary color is the Trux blue **`#1E3A8A`** in light mode and the light blue **`#93C5FD`** in dark mode (hover states
`#172554` and `#BFDBFE`). `assets/scss/_trux-brand.scss` sets Bootstrap's primary color for both the landing page and the
docs pages. `assets/docs/scss/custom/colors/_trux.scss` is the docs palette, selected with `themeColor = "trux"` in
`hugo.toml`: it sets the CSS variables Lotus Docs uses for links, buttons, the sidebar, the table of contents, and search,
plus the logo color. The landing page has no dark mode in Lotus Docs.

More detail: [Working on the documentation site](https://thea1lab.github.io/trux/docs/internals/contributing/#working-on-the-documentation-site).

## Markdown for AI tools

Every docs page is also published as Markdown next to its HTML, at `<page URL>index.md` (for example
<https://thea1lab.github.io/trux/docs/guide/types/index.md>). Each page has a **Copy page as Markdown** button that
copies it, and its `<head>` links it with `rel="alternate" type="text/markdown"`. The site root also has [`llms.txt`](https://thea1lab.github.io/trux/llms.txt) (an index of all pages) and
[`llms-full.txt`](https://thea1lab.github.io/trux/llms-full.txt) (every page in one file).

The Markdown is built from each page's source by `layouts/partials/page-markdown.md`, which inlines `include`d files
(honouring line ranges), turns alerts, tabs, and collapsible blocks into plain Markdown, and rewrites `/docs/...` links
to absolute URLs. **If you add a new shortcode to the content, add a pattern for it there**: the build fails when
shortcode syntax is left in the Markdown, and `check-markdown-output.sh` checks the built files again in CI.
